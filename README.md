# YOLOv8n PCB defect detection comparison

A local FYP comparison of the original YOLOv8n and the Trial 044 enhancement.

1. Read the [results report](custom_yolo_pcb/RESULTS_REPORT.md) for training curves, final metrics, per-class results, confusion matrices, and validation examples.
2. Follow the [Windows / VS Code guide](custom_yolo_pcb/README.md) to prepare the dataset or run the comparison.
3. Open [reproducibility details](custom_yolo_pcb/reproducibility/README.md) for configs, hashes, tests, notices, and historical evidence.

The models use different training and validation authorities. The results are not a controlled same-data ablation. Held-out test evaluation was not run; all reported performance is validation-only. The dataset is supplied separately as a private Release ZIP.
